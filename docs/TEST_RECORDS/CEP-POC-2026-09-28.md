## Implemented boundary

- typed host protocol with version validation;
- response validation for snapshots and operation results;
- serialized CEP calls to protect operation order;
- `evalScript` timeout;
- static ExtendScript read/execute entrypoint;
- composition/layer preflight and stale revision guard;
- one Undo Group per command;
- rollback attempt on host-side exception;
- preliminary dockable panel shell with read/refresh only.

## Limitations

The PoC has not been installed or run in After Effects. It does not establish CEP runtime compatibility, actual `Layer.id` behavior, timing precision against AE, save/reopen behavior, native visual equivalence, or Undo correctness. `client/CSInterface.js` is included from Adobe CEP Resources CEP 12; its source and notice are recorded in `THIRD_PARTY_NOTICES.md`.
