## Текущий этап — недостающие контекст проекта и таблица команд

База: `12ec6b0d46440f3259a0280d9722b480ff7b1921`. Правила main перечитаны:
blob `701a8c1ae3acb4dbfe1d7eda94acbf8095b88608`.

Подготовлен самостоятельный offline-профиль `Queue-Context.command`.
Он не ищет старую папку и не повторяет прежний запрос 19 функций. Собираются
четыре точных имени из полученного отчёта: BEE_QueryProject,
BEE_GetCurrentConstProject, конструктор/деструктор BEE_ProjectSetContext.
AddFunctionToQueue повторно читается только как опора для таблицы переходов.

Четыре недостающих байта таблицы читаются из файла по проверенному отображению
VM-адреса в arm64 Mach-O. Адрес привязан к точному hash BEE; произвольные адреса
через CLI не принимаются. Неоднозначность, неверная сборка, отсутствие тела,
ошибка отображения или изменение файла оставляют BLOCKED, а не частичный PASS.
Узкий перечень имён для поиска вызывающей стороны/emitter тоже сохраняется;
имена сами по себе не доказывают назначение или безопасный внешний контракт.

Переиспользован существующий Mach-O parser; новый reader включён в manifest
пакета и загружается только после проверки байтов. Прежний режим семи корневых
функций сохранён. Нет запуска AE, отладчика, установки или чтения проектов.

Локально: 20 тестов, 19 PASS, один Apple-linker контроль NOT RUN на Linux.
Местный ld64.lld не поддерживает macOS; обязательная проверка настоящего
Mach-O остаётся в macOS CI, включая reader из точного ZIP. Полный CI и hash
передаваемого пакета относятся только к содержащему commit и фиксируются в PR #2.
[Критерии, происхождение запроса, проверки и ограничения](TEST_RECORDS/QUEUE-CONTEXT-GAPS-2026-09-30.md).

**Новых выводов о выполнении уведомлений в AE нет.** Тела четырёх helpers и
байты таблицы пока не получены. Следующий вход — один новый offline-отчёт
после проверки точного пакета; предыдущий отчёт повторять не требуется.

## Подтверждённая база исследования

`FSTR-AE-Queue-qk6xsvhj`: 19 тел, 26 успешных команд, 5 029 четырёхбайтовых
позиций. Целостность и связь с пакетом `eef15f5` проверены. По коду этой сборки:
вставка в конец/извлечение с начала; вызов после удаления и снятия блокировки;
отмена может очистить очередь; project ID проверяется после вызова.

в clone. Getters не дают подтверждённого внешнего владения. RegisterListener
использует другую структуру; её emitter, связь с очередью и время жизни открыты.
