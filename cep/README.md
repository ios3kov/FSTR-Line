# CEP PoC

This directory contains the minimal dockable CEP read/refresh proof of concept.

## Runtime contract

- Host: After Effects `22.0+` is the preliminary target because `Layer.id` was added in AE 22.0.
- CEP: the manifest uses the CEP 7 schema/runtime declaration; the actual AE/CEP combination is not verified yet.
- Host bridge: `client/app.js` calls only `fstrLineHost.readSnapshot()` through `CSInterface.evalScript()`.
- ExtendScript entrypoint: `host/host.jsx` validates the snapshot/command protocol, but runtime behavior requires real After Effects.

## Vendor file

`client/CSInterface.js` is the Adobe CEP 12 runtime bridge sourced from Adobe CEP Resources. It is intentionally not generated by the TypeScript build. The final package records its payload hash; the source and notice are recorded in `THIRD_PARTY_NOTICES.md`.

## Build

```bash
npm run build:cep
```

The command generates `client/app.js`. The generated bundle is ignored by Git and must be treated as an artifact of the current commit.

It also generates `build-manifest.json` with the source commit, dirty state and SHA-256 for each CEP payload file. The manifest is generated output and is ignored by Git.

## Current status

The shell and protocol are statically checked. Loading the panel, reading a real composition, and validating dockability remain `BLOCKED` until tested inside the target After Effects/CEP environment.
